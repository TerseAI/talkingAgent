# Talking Agent interface

The web app uses a pale green voice console alongside a white transcript panel. Forest green identifies actions; local Manrope variable fonts carry the web typography. Live connection and microphone states remain explicit. On narrow screens the controls precede the transcript.

Shared counter progress sits above the conversation controls and transcript. The panel shows agent-reported count and the talking-stick holder. One conversation supports speech, text, interruptions, and optional counting through tools. The native experiment is outside the current web workflow.
