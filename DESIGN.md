# Talking Agent interface

The web app uses a pale green voice console alongside a white transcript panel. Forest green identifies actions; local Manrope variable fonts carry the web typography. Live connection and microphone states remain explicit. On narrow screens the controls precede the transcript.

Counting mode places shared progress above the existing console and transcript. The shared panel shows the completed count, next number, and talking-stick holder. Each voice console identifies only its own agent and session state. A mode selector preserves voice chat. The native experiment is outside the current web workflow.
